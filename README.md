# JS Vowel Skip

A simple JavaScript project that removes all vowels from the user's input using **nested while loops**. This project was built to practice JavaScript fundamentals, including loops, string manipulation, boolean flags, and DOM manipulation.

## Live Demo

https://madhushreerasal.github.io/JS-Vowel-skip/

## Preview

![JS Vowel Skip Preview](images/preview.png)

## Features

- Removes both uppercase and lowercase vowels
- Uses nested `while` loops
- Beginner-friendly JavaScript logic
- Simple and responsive user interface
- Instant output without reloading the page
